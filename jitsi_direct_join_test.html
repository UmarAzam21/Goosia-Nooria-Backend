Troubleshooting

Issue: Landing on Jitsi Homepage

  • ✗ Wrong: https://meet.jitsi.net/ (no room name)
  • ✗ Wrong: https://meet.jitsi.net/Noori123 (mixed case)
  • ✓ Correct: https://meet.jitsi.net/noorib9e224cc42 (lowercase, 15 chars)

Issue: Meeting doesn't load

  • Check URL has correct room name (lowercase, no spaces)
  • Verify browser allows camera/microphone access
  • Try in different browser (Chrome, Firefox, Safari)

Issue: Multiple students see different rooms

  • Ensure same course = same room ID (deterministic from course name)
  • Check backend is generating consistent IDs

✓ Expected Behavior

  • Click link → Browser opens new tab
  • New tab shows Jitsi interface (not homepage)
  • Camera/mic permissions prompt appears
  • Meeting room loads and auto-starts
  • Multiple users can join same room with same URL
